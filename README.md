# Chukl Discord

Android companion app that shows **Playing ChuklAddon** on your Discord profile while Zalith Launcher is open.

- Built with the Discord Social SDK (the SDK is downloaded from this repo's `Sdk` release during the build).
- The APK is built by GitHub Actions (`Build APK` workflow). Download it from the run's **Artifacts**.
- Discord redirect address (Developer Portal → OAuth2 → Redirects): `discord-1569968585475100722:/authorize/callback`
- The Discord application must be set to a **Public Client** (OAuth2 tab).
